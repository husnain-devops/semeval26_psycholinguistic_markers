─────────────────────────────────────────────────────────────

🆘 TROUBLESHOOTING:
   
   Out of memory?
   → Reduce BATCH_SIZE to 4 or 2
   → Reduce MAX_LENGTH to 128
   
   Slow training?
   → Check GPU: nvidia-smi / rocm-smi
   → Increase batch size if memory allows
   
   Poor performance?
   → Increase epochs
   → Try different learning rates
   → Use roberta-large

─────────────────────────────────────────────────────────────

📝 DATA FORMAT:
   
   Input (train_rehydrated.jsonl):
   {
     "_id": "...",
     "text": "US backed coups...",
     "markers": [
       {"startIndex": 0, "endIndex": 2, 
        "type": "Actor", "text": "US"}

   Output (predictions.jsonl):

     "_id": "...",
     "markers": [
       {"startIndex": 0, "endIndex": 2, "type": "Actor"}
